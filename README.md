
Task 1: Data Wrangling and Data Cleaning

Project Overview

This project focuses on cleaning and preparing a sales dataset
using Python and Pandas.

Tools Used

Python
Pandas
Matplotlib
Google Colab

Dataset Columns

OrderID: Identifier for an order
Product: Product name
Quantity: Number of units ordered
Price: Price per unit
City: City where the order was placed
TotalSales: Quantity multiplied by Price

Data Cleaning Steps

1. Loaded and inspected the dataset.
2. Checked dataset dimensions and column data types.
3. Identified missing values.
4. Removed duplicate rows.
5. Replaced missing numeric values with their column medians.
6. Standardized city names.
7. Created the TotalSales column.
8. Saved the cleaned dataset as a CSV file.

Results

Original records: 8
Records after duplicate removal: 7
Missing values after cleaning: 0
Duplicate rows after cleaning: 0

Output Files

cleaned_sales_data.csv
data_dictionary.csv

Conclusion

The dataset was cleaned and prepared for basic sales analysis.
